Скилл: погода (wttr.in)
Тип: инструкция к публичному API, без авторизации.

## When to Use

✅ Используй этот скилл, когда пользователь спрашивает:

- «Какая погода в \<город\>?»
- «Будет ли дождь сегодня/завтра в \<город\>?»
- Температура / ветер / осадки для конкретного города
- Погода при планировании поездки

## When NOT to Use

❌ Не используй этот скилл, когда:

- Вопрос не про текущую погоду или ближайший прогноз (история погоды,
  климатическая статистика) — для этого нет источника данных, честно скажи,
  что не знаешь, вместо того чтобы придумывать.
- Город не назван — спроси у пользователя, для какого города нужна погода,
  не угадывай.

## Location

Город указывай латиницей или транслитом, пробелы заменяй на `+`,
например `Minsk`, `Moscow`, `New+York`.

## Commands

Текущая погода (компактно):

```
curl -s --max-time 15 "wttr.in/<город>?0"
```

Подробнее / прогноз на несколько дней:

```
curl -s --max-time 15 "wttr.in/<город>?2"
```

## Notes

- Ключ API не нужен, сервис публичный (wttr.in).
- Таймаут запроса ограничен таймаутом инструмента exec — если wttr.in
  не отвечает, сообщи пользователю, что сервис погоды сейчас недоступен,
  вместо того чтобы придумывать данные.
- Сводку пользователю пиши по-русски, кратко: 2–4 предложения
  (погода, температура, ветер/осадки).

## Пример

Вопрос «Какая погода в Минске?» → выполняешь:

```
curl -s --max-time 15 "wttr.in/Minsk?0"
```

и по выводу отвечаешь пользователю сводкой по-русски.
