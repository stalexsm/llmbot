# llmbot — минимальный AI-агент в Telegram

Telegram-бот, подключённый к локальной LLM через Ollama и превращённый в автономного агента: модель выполняет действия в системе через инструменты и текстовые инструкции (скиллы), а не только отвечает текстом.

## Language

**Харнесс (Harness)**:
Код-обвязка вокруг модели: собирает запрос, крутит агентный цикл, выполняет инструменты.
_Avoid_: обвязка, framework, бот (бот — это Telegram-слой)

**Агентный цикл (Agentic Loop)**:
Цикл «ответ модели → выполнение инструментов → следующий запрос к модели», повторяемый до финального ответа или лимита шагов.
_Avoid_: retry-цикл, инференс (инференс — один вызов модели)

**Запуск агента (Agent Run)**:
Один экземпляр агентного цикла: от сообщения пользователя до финального ответа или упора в лимит шагов. Единица учёта токенов, времени и стоимости.
_Avoid_: задача, task, turn (turn — это шаг), сессия (сессия — вся история чата)

**Шаг**:
Один ответ модели внутри агентного цикла. Ответ с вызовами инструментов продолжают цикл, ответ без них — финальный.
_Avoid_: итерация, попытка, retry (задание называет лимит «Max Retries» — это не повторы, это шаги)

**Лимит шагов**:
Максимальное число шагов в одном агентном цикле; защита от зацикливания. Настраивается переменной окружения.
_Avoid_: max retries

**Финальный ответ**:
Ответ модели без вызовов инструментов; завершает агентный цикл и уходит пользователю.
_Avoid_: итоговый текст

**Инструмент**:
Действие, которое модель может запросить у харнесса по имени с JSON-аргументами. Единственный инструмент — exec.
_Avoid_: функция, команда (команда — это то, что передаётся внутрь exec)

**exec**:
Инструмент выполнения консольной команды в shell на машине агента.
_Avoid_: bash, terminal

**Скилл**:
Каталог `skills/<имя>/` c файлом `SKILL.md`: markdown-инструкция для агента — правила CLI/API или пошаговая рутина. Шапка frontmatter несёт `name` и `description`.
_Avoid_: инструкция, промпт, докаментация

**Индекс скиллов**:
Перечень скиллов (имя + краткое описание), помещаемый в системный промпт; модель читает сам файл по необходимости через exec.
_Avoid_: список скиллов, каталог

**Чат-сессия**:
История сообщений одного Telegram-чата, единый длинный контекст агента. Сбрасывается командой /new.
_Avoid_: диалог, чат (чат — это Telegram-сущность), память

**/new**:
Команда пользователя: начать новую чат-сессию — история предыдущей отбрасывается.
_Avoid_: reset, restart

**Документ**:
Файл, присланный пользователем боту и прошедший индексацию: доступен поиску по содержимому. До индексации — просто файл; после удаления из корпуса — снова просто файл.
_Avoid_: вложение, attachment

**Владелец документа**:
Пользователь Telegram, от лица которого документ загружен. Корпус документов одного владельца изолирован от корпусов других: поиск никогда не выходит за пределы корпуса владельца.
_Avoid_: хозяин, автор файла

**Чанк (Chunk)**:
Фрагмент документа, на который он разбит при индексации; единица эмбеддинга и единица результата поиска. Имеет порядковый номер внутри документа.
_Avoid_: кусок, отрывок

**Эмбеддинг**:
Векторное представление чанка или поискового запроса; близость эмбеддингов — основа поиска по документам.
_Avoid_: векторизация

**Индексация**:
Превращение файла в документ: извлечение текста, разбиение на чанки, получение эмбеддингов, запись в хранилище. Завершается либо документом, доступным поиску, либо понятной ошибкой.
_Avoid_: обработка, парсинг (парсинг — только извлечение текста), загрузка

**RAG**:
Ответ на вопрос с опорой на найденные чанки: агент сам решает, когда искать, и отвечает только по найденному. Приём целиком, а не его отдельные стадии.
_Avoid_: поиск по документам (это инструмент внутри RAG), retrieval

**Поиск по документам (search_documents)**:
Инструмент агента: находит чанки из корпуса одного владельца, релевантные поисковому запросу, и отдаёт их вместе с источниками.
_Avoid_: RAG, полнотекстовый поиск

**Поисковый запрос**:
Самостоятельная формулировка вопроса без ссылок на контекст разговора; по ней выполняется поиск.
_Avoid_: вопрос (вопрос — реплика пользователя), query

**Источник**:
Документ и, где доступно, страница, из которых агент взял ответ; прикладывается к каждому ответу с опорой на документы.
_Avoid_: ссылка, атрибуция

**/documents**:
Команда пользователя: показать документы своего корпуса.
_Avoid_: список файлов

**/delete**:
Команда пользователя: удалить документ из корпуса по имени; вместе с ним удаляются его чанки и эмбеддинги.
_Avoid_: rm, стереть

**/clear**:
Команда пользователя: очистить свой корпус — удалить все его документы вместе с чанками и эмбеддингами. Корпуса других владельцев не затрагиваются.
_Avoid_: сброс, дроп базы (команда работает только с корпусом владельца)
