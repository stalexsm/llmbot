# llmbot — минимальный AI-агент в Telegram

Telegram-бот, подключённый к локальной LLM через Ollama и превращённый в автономного агента: модель выполняет действия в системе через инструменты и текстовые инструкции (скиллы), а не только отвечает текстом.

## Language

**Харнесс (Harness)**:
Код-обвязка вокруг модели: собирает запрос, крутит агентный цикл, выполняет инструменты.
_Avoid_: обвязка, framework, бот (бот — это Telegram-слой)

**Агентный цикл (Agentic Loop)**:
Цикл «ответ модели → выполнение инструментов → следующий запрос к модели», повторяемый до финального ответа или лимита шагов.
_Avoid_: retry-цикл, инференс (инференс — один вызов модели)

**Шаг**:
Один ответ модели внутри агентного цикла. Ответ с вызовами инструментов продолжают цикл, ответ без них — финальный.
_Avoid_: итерация, попытка, retry (задание называет лимит «Max Retries» — это не повторы, это шаги)

**Лимит шагов**:
Максимальное число шагов в одном агентном цикле; защита от зацикливания. Настраивается переменной окружения.
_Avoid_: max retries

**Финальный ответ**:
Ответ модели без вызовов инструментов; завершает агентный цикл и уходит пользователю.
_Avoid_: итоговый текст

**Инструмент**:
Действие, которое модель может запросить у харнесса по имени с JSON-аргументами. Единственный инструмент — exec.
_Avoid_: функция, команда (команда — это то, что передаётся внутрь exec)

**exec**:
Инструмент выполнения консольной команды в shell на машине агента.
_Avoid_: bash, terminal

**Скилл**:
Markdown-файл в `skills/` со специализированной инструкцией для агента: правила CLI/API или пошаговая рутина.
_Avoid_: инструкция, промпт, докаментация

**Индекс скиллов**:
Перечень скиллов (имя + краткое описание), помещаемый в системный промпт; модель читает сам файл по необходимости через exec.
_Avoid_: список скиллов, каталог

**Чат-сессия**:
История сообщений одного Telegram-чата, единый длинный контекст агента. Сбрасывается командой /new.
_Avoid_: диалог, чат (чат — это Telegram-сущность), память

**/new**:
Команда пользователя: начать новую чат-сессию — история предыдущей отбрасывается.
_Avoid_: reset, restart
