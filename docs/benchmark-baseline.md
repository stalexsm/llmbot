# Baseline-бенчмарк до оптимизаций (PR №1)

Первый зафиксированный прогон headless-бенчмарка (`uv run python -m bot.benchmark`)
по 20 offline-задачам против живого Ollama (модель `qwen3:1.7b`, состояние
репозитория на ветке `token-audit`, коммит с этим файлом). Это точка отсчёта
для сравнения до/после оптимизаций контекста в PR №2.

Критерии:

- **success** — финальный ответ в пределах лимита шагов без ошибки (тикет 06);
- **answer** — содержательная проверка ответа чекером задачи;
- токены — input/output, суммарно сообщённые моделью за все шаги запуска.

## Как перезапустить

```sh
uv run python -m bot.benchmark   # требует живого Ollama с моделью qwen3:1.7b
```

Прогон пишет метрики в общий JSONL (`.data/metrics/`), запуски помечены
`request_id` вида `bench-<task_id>`.
