# 03: Загрузка документов в Telegram (.txt end-to-end)

**What to build:** пользователь присылает боту .txt — мгновенно получает «Документ получен», индексация идёт фоновой задачей под блокировкой на владельца, прогресс показывается одним редактируемым статус-месседжем (стадии: извлечение → N чанков → эмбеддинги → готово; правки не чаще ~1.5 с; если правка невозможна — новое сообщение), затем «Документ готов». Повторная отправка того же имени заменяет документ атомарно. /documents показывает корпус владельца; /delete по имени удаляет документ вместе с чанками и эмбеддингами, без подтверждения; при неизвестном имени — дружелюбная ошибка со списком. Все ошибки задания (неподдерживаемый формат, пустой документ, слишком большой: ≤20 MB / ≤200k символов / ≤300 чанков, сбой эмбеддинг-модели, SQLite, Telegram API, таймаут) превращаются в понятные сообщения, бот не падает.

**Blocked by:** 02 (RAG-ядро: txt → чанки → эмбеддинги → rag-БД → поиск)

## Comments

- Реализация: rag-слой — `RagService.list_documents/delete_document`, `RagStore.list_documents/delete_document` (чанки и векторы — одной транзакцией), стадии прогресса — `rag/progress.py` (`IndexingStage`, `DocumentIndexProgress`, заглушка). Application — `application/documents.py`: `DocumentService` с блокировкой на владельца (чат не блокируется, замена атомарна — поиск во время индексации видит старый корпус). Telegram — `handlers.handle_document/handle_documents/handle_delete`, статус-месседж `telegram/progress.py` (троттлинг 1.5 с, фолбэк на новое сообщение), скачивание файла — `telegram/loader.py` (протокол `DocumentLoader`). Композиционный корень собирает `OllamaEmbeddingProvider` → `RagService` → `DocumentService` → хендлеры.
- Владелец — `TelegramUserId` с границы Telegram-слоя; сообщение/команда без автора получают понятную ошибку и до сервисов не доходят (ADR-0002).
- Ошибки задания (формат, пустой документ, лимиты 20 MB / 200k символов / 300 чанков, эмбеддинг-модель, rag-БД, Telegram API) маппятся в прикладные исключения и рендерятся понятными текстами тем же статус-месседжем.
- Тесты: `tests/unit/rag/test_lifecycle.py`, `tests/unit/application/test_documents.py` (сериализация владельцев — реальный SQLite во временном файле + замедленная фейковка эмбеддингов), `tests/unit/telegram/test_document_handlers.py`, `tests/unit/telegram/test_progress.py` (замоканный Telegram API).
