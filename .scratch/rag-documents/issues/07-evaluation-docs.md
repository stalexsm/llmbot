# 07: Evaluation, калибровка порога, документация

**What to build:** проверка того, что retrieval действительно находит правильные чанки, и финальная документация. Датасет минимум из 5 вопросов с известными источниками; команда прогона против живого Ollama печатает по каждому вопросу найденные чанки и попадание/промах; стартовый порог «не найдено» калибруется по результатам и фиксируется в конфиге. README дополняется разделами задания; architecture.md доводится до фактического состояния; чек-лист acceptance criteria задания закрывается целиком.
