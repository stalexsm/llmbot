# 04: search_documents как инструмент агента (+ скоуп владельца)

**What to build:** пользователь спрашивает по документу обычным сообщением — агент сам решает, что нужен поиск, и вызывает инструмент поиска по документам; получает чанки с источниками либо явное «ничего не найдено»; отвечает с указанием Источника, а при отсутствии информации честно говорит, что не нашёл её в документах. Контракт инструмента расширяется контекстом выполнения со скоупом владельца: цикл прокидывает контекст, существующий exec-инструмент его игнорирует; application-слой передаёт владельца от запроса. Системный промпт дополняется правилами: отвечать только результатом инструмента, указывать Источник, честно сообщать об отсутствии. Вызовы поиска учитываются существующими метриками инструментов без записи содержимого запросов.

## Comments

- Контекст выполнения: `ExecutionContext` (`domain/tools.py`) со скоупом владельца (`owner_id: TelegramUserId | None`); `Tool.execute` принял четвёртый параметр, `AgentLoop.run` — аргумент `context`; `ApplicationService` строит контекст из `UserMessageRequest.user_id` (ADR-0002). `ExecTool` контекст игнорирует (`del context`), `MeteredTool` прокидывает насквозь.
- Инструмент: `SearchDocumentsTool` (`application/search.py`) — структурно реализует `Tool` над `RagService.search` (application → agent и application → rag — существующие рёбра зависимостей). Чанки форматируются с Источником (документ, страница, фрагмент); пустой результат ниже порога и сбои (эмбеддинги, rag-БД) — `ToolResult` без разрыва цикла.
- Метрики: `MeteredTool` пишет не-exec инструменты под именем спеки (`search_documents`), exec — как раньше (`exec:<класс>`); содержимое запроса и чанков не записывается.
- Промпт: два правила про документы (поиск через search_documents + Источник; честное «не нашёл»), бюджет базы поднят 900 → 1150 символов с якорями в `TestPromptBudget`.
- Композиционный корень: rag-блок поднят выше сборки цикла; `AgentLoop(tools=(metered_exec, metered_search))`. Таблица контрактов `docs/architecture.md` помечена примечанием; текст документа — тикет 07.
- Тесты: юнит инструмента (`tests/unit/application/test_search_tool.py`, включая изоляцию владельцев), прокидывание контекста (`test_loop.py`), имя инструмента в метриках (`test_tool.py`), E2E (`tests/integration/test_search_tool.py`: ответ с Источником, честное «не нашёл», изоляция сквозь стек). Эмбеддинги — детерминированная фейковка «ключевое слово — ось» `KeywordEmbeddingProvider` в `tests/fakes.py`.
