# 09: Третья оптимизация по данным аудита + отчёт до/после

**What to build:** по данным промежуточного аудита (bench с мониторингом) выбирается и внедряется третья оптимизация из списка: динамическое окно истории по токенам; чтение обычных файлов фрагментами (правка системного промпта); сжатие системного промпта. Скиллы не трогаются: индекс минимальный, полный файл читается по требованию. Затем — повторный bench-прогон после всех оптимизаций и итоговый отчёт до/после в docs: методика, цифры, guard качества. Тикет закрывает PR №2.
