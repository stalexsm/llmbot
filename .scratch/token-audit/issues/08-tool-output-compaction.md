# 08: Компакция старших tool-выводов (K=3)

**What to build:** при сборке запроса в агентном цикле выводы инструментов шагов старше K=3 схлопываются в сигнатуру «команда → ok/ошибка» (без тела вывода; модель может перечитать командой). **Blocked by:** None (can start immediately).
