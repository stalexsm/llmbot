# 05: CLI-dashboard: агрегат и timeline запуска

**What to build:** владелец запускает `uv run python -m bot.report` и видит текстовый dashboard из задания: всего токены (input/output), estimated cost, средний запуск (токены, шаги, вызовы инструментов), доля повторного контекста, топ классов команд по токенам.
