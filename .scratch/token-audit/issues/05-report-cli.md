## Answer

`src/bot/report/` (точка входа `uv run python -m bot.report [--task <id>]`):
`events.py` — чтение JSONL метрик в типизированные записи (битые строки
пропускаются, отсутствующий файл — пустой отчёт); `aggregate.py` и
`timeline.py` — чистые функции от событий (сводка и пошаговый timeline);
`render.py` — отрисовка текста; `cli.py` — разбор аргументов и stdout;
`sums.py` — общие суммы опциональных счётчиков. Блоки dashboard из задания
присутствуют (Runs completed, Total tokens, Estimated cost, Average run,
Cache hit rate, Most expensive tools); формат чисел воспроизводит пример
задания (39.4k, 0.8M, 8,200). CLI вне графа зависимостей бота — Settings и
секреты не нужны. Гейты: `uv run ty check`, `uv run ruff check .`,
`uv run ruff format --check .`, `uv run pytest` (271 passed) — зелёные.
Ревью по двум осям: замечания P2 (дублирование сумм, голый str в контракте
`build_timeline`, дублирование пути метрик) устранены; формат токенов и
мелкий UX итоговой строки оставлены как задумано.
