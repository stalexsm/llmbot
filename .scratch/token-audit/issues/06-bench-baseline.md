# 06: Bench: 20 offline-задач, headless-прогон, baseline

**What to build:** в репозитории живёт фиксированный набор из 20 offline-детерминированных задач (5 «из знаний», 5 одношаговых exec, 6 многошаговых по репозиторию, 4 смешанных) и headless-раннер: прогон напрямую через агентный цикл против живого Ollama, без Telegram. Раннер печатает по каждой задаче success/токены и сводку по набору. Первый прогон фиксируется как baseline до оптимизаций.

## Comments

- Реализовано агентом на ветке `token-audit`. Новый пакет `src/bot/benchmark/`: `tasks.py` — фиксированный набор из 20 задач (5 knowledge / 5 exec / 6 repo / 4 mixed, чекеры — чистые предикаты; части привязаны к текущему состоянию репозитория и пересчитываются при проверке); `tracker.py` — декоратор на шве `InferenceProvider`, копящий usage по `request_id` в памяти; `runner.py` — headless-прогон через `AgentLoop` (`TaskResult`, `BenchmarkSummary`); `settings.py` — `Settings` с необязательным Telegram-токеном; `cli.py` + `__main__.py` — запуск `uv run python -m bot.benchmark`, печатает per-task success/токены и сводку. Живой прогон дополнительно завёрнут в `MeteredInferenceProvider`, поэтому метрики `bench-*` попадают в общий JSONL и отчёт `bot.report`.
- Юнит-тесты: `tests/unit/benchmark/` (16) — состав набора, чекеры на верных/неверных ответах, трекер токенов, раннер на скриптованном провайдере (успех, провал чекера, лимит шагов, исключение провайдера, сводка).
- Живой прогон выполнен локально против Ollama (`qwen3:1.7b`): success rate 20/20 (100%), верных ответов 15/20, средние токены на запуск input 1708 / output 420 / total 2128. Цифры зафиксированы в `docs/benchmark-baseline.md` как baseline до оптимизаций.
- Гейты: `uv run ty check`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run pytest` (287 passed) — зелёные.
