# 03: Индекс скиллов и погодная рутина

**What to build:** У агента появляются скиллы — markdown-файлы с инструкциями в каталоге скиллов. Системный промпт содержит индекс скиллов (имя + краткое описание); полный текст модель читает сама через exec по необходимости. Первый скилл — рутина типа B «погода»: пользователь спрашивает о погоде в Минске, агент находит скилл в индексе, читает файл, выполняет curl-запрос погодного сервиса, формирует сводку по-русски. Добавление нового скилла = добавление файла, без правки кода.

**Blocked by:** 02 (модель читает скиллы через exec)

**Status:** done

- [x] Полный текст скилла не попадает в промпт автоматически
- [x] По вопросу о погоде агент сам читает файл скилла через exec
- [x] Скилл погоды: curl-запрос к погодному сервису (Минск), сводка по-русски end-to-end

## Comments

Реализация: `bot.agent.skills` (frontmatter-парсер + табличные чистые функции),
`build_system_prompt` поверх базового промпта, `AGENT_SKILLS_DIRECTORY` в Settings,
сборка индекса в композиционном корне на старте. Раскладка — каноническая для
скиллов: один каталог на скилл, `skills/<имя>/SKILL.md`, шапка YAML frontmatter
с `name:` и `description:` (запасной вариант — строка `Description:`).

Проверено на живой модели qwen3:1.7b: сценарий «Какая сейчас погода в Минске?»
проходит end-to-end (cat скилла → `curl 'wttr.in/Minsk?0'` → сводка по-русски),
но не каждый запуск: модель периодически игнорирует шаг чтения файла и зовёт
выдуманный погодный API из своих знаний (потом честно отчитывается об ошибке).
На живых прогонах цикла 2 из 5 собрались правильно.

Отдельно исследовали чувствительность к формулировкам индекса: простые пункты
вида «- вопрос о погоде: файл …» модель читает безотказно (десятки прогонов),
но добавить туда же имя и описание из спеки — и она ложится на лезвие:
тот же смысл, переставленные слова — и стабильность исчезает; поведение модели
нестабильно даже между соседними сериями прогонов. Это свойство модели 1.7B,
а не промпта. Рекомендация на будущее: брать модель покрупнее (qwen3:8b+);
для 1.7B ожидать скилл-флоу можно только при удачном стечении формулировок.
