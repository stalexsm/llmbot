# 04: Allowlist чатов и длинные ответы

**What to build:** Безопасность и UX-полировка: список разрешённых чатов через переменную окружения (идентификаторы через запятую). Если список пуст — бот отвечает всем (текущее поведение, домашка не ломается без настройки); если заполнен — сообщения из чужих чатов молча игнорируются. Длинные финальные ответы больше не теряются: текст разбивается на несколько сообщений телеграм-совместимой длины (~4000 символов, разрыв по границам строк/абзацев), части приходят по порядку.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] С пустым списком бот отвечает любому чату (поведение не изменилось)
- [x] С заполненным списком сообщения из чужих чатов игнорируются без ответа и ошибок
- [x] Чаты из списка работают как раньше (включая команды и шаги агента)
- [x] Ответ длиннее лимита приходит несколькими сообщениями по порядку
- [x] Разрывы частей приходятся на границы строк/абзацев, а не середину слова
- [x] Тесты: allowlist (пустой/заполненный) на хендлерах с подменённым сервисом; сплиттер как чистая функция — таблично (короткий, ровно на границе, длинный, без переносов)
