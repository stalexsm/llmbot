# 02: Агентный цикл и инструмент exec

**What to build:** Сообщение пользователя запускает агентный цикл: модель либо даёт финальный ответ (цикл завершён), либо запрашивает консольную команду через инструмент exec — харнесс выполняет её в shell (одна строка, рабочий каталог — корень проекта) и возвращает модели exit code + stdout + stderr (суммарно обрезано до ~4000 символов), цикл продолжается. Протокол инструментов — нативный (описания инструментов в запросе, tool-calls в ответе, результат сообщением с ролью инструмента); режим размышлений модели отключён. Лимит шагов (по умолчанию 10, настраивается) защищает от зацикливания; при превышении пользователь получает честное сообщение о остановке. Пользователь видит шаги: перед командой приходит сообщение с командой, после выполнения оно редактируется в отметку об успехе. Финальный ответ уходит как обычный текст.

**Blocked by:** 01 (цикл читает и пишет чат-сессию)
